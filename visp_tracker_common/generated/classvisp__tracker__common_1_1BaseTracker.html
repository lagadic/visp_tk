Protected Types

enum InitializationMethod

Enumeration that list the different ways of initializing the trackers.

Values:

enumerator CLICK

The initialization of the tracker is done through user-interaction by clicking on particular points in the image. Requires visp_gui.

enumerator TOPIC

When the tracker is not initialized, it will listen on a dedicated topic to get the initial pose.

enumerator FILE

When the tracker is not initialized, it will read the file that is given as node parameter.

enumerator INITIALIZATION_METHOD_COUNT

Number of initilialization method.
